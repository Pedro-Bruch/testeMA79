Sistema de Cadastro de Motores em Python

Documentação técnica da arquitetura monolítica desenvolvida em memória para testes de lógica e manipulação de dados.

Contexto do Projeto

Este projeto foi desenvolvido durante as atividades de capacitação técnica no SENAI dentro da WEG (CentroWEG), localizado em Jaraguá do Sul – SC. O objetivo da aplicação é simular um sistema de controle e registro de motores aplicando conceitos fundamentais de lógica de programação, modularização com funções e estruturas de dados nativas do Python, dispensando o uso de bancos de dados externos.

Arquitetura e Funcionamento do Código

O algoritmo foi estruturado de forma monolítica em um único arquivo .py, dividido nas seguintes camadas lógicas:

1. Armazenamento em Memória

Utiliza uma lista nativa (motores = []) funcionando como um array dinâmico. Cada motor cadastrado é armazenado como um dicionário contendo chaves específicas (ID, modelo, fabricante, potência, cilindrada e combustível).

2. Controle de Identificador (ID)

A variável global proximo_id garante a integridade referencial dos registros, atribuindo um número único sequencial a cada nova inserção, sem repetir IDs mesmo após exclusões.

3. Operações CRUD via Funções

Cada responsabilidade foi isolada em uma função dedicada: cadastrar_motor(), listar_motores(), buscar_motor(), atualizar_motor() e remover_motor().

4. Tratamento de Exceções

Blocos try / except ValueError protegem a execução contra entradas inválidas (como digitar letras em campos numéricos de potência ou ID), evitando que o programa seja encerrado abruptamente.

Código-Fonte Completo (Python)

Abaixo está a implementação completa utilizada para execução via terminal:

# Lista (array) que funcionará como nosso banco de dados em memória
motores = []
proximo_id = 1

def cadastrar_motor():
    global proximo_id
    print("\n--- Cadastrar Novo Motor ---")
    modelo = input("Modelo do motor: ").strip()
    fabricante = input("Fabricante: ").strip()
    
    try:
        potencia_cv = float(input("Potência (cv): "))
        cilindrada_cc = int(input("Cilindrada (cc): "))
    except ValueError:
        print("Erro: Potência e cilindrada devem ser valores numéricos. Cadastro cancelado.")
        return

    combustivel = input("Tipo de combustível (Gasolina, Etanol, Diesel, Elétrico, Flex): ").strip()

    motor = {
        "id": proximo_id,
        "modelo": modelo,
        "fabricante": fabricante,
        "potencia_cv": potencia_cv,
        "cilindrada_cc": cilindrada_cc,
        "combustivel": combustivel
    }

    motores.append(motor)
    proximo_id += 1
    print(f"Sucesso: Motor '{modelo}' cadastrado com ID {motor['id']}!")

def listar_motores():
    print("\n--- Lista de Motores Cadastrados ---")
    if not motores:
        print("Nenhum motor cadastrado no momento.")
        return

    for m in motores:
        print(f"ID: {m['id']} | Modelo: {m['modelo']} | Fabricante: {m['fabricante']} | "
              f"Potência: {m['potencia_cv']} cv | Cilindrada: {m['cilindrada_cc']} cc | "
              f"Combustível: {m['combustivel']}")

def buscar_motor():
    print("\n--- Buscar Motor ---")
    termo = input("Digite o ID ou parte do nome do modelo: ").strip().lower()
    encontrados = [m for m in motores if str(m["id"]) == termo or termo in m["modelo"].lower()]

    if not encontrados:
        print("Nenhum motor encontrado com esse critério.")
    else:
        for m in encontrados:
            print(f"ID: {m['id']} | Modelo: {m['modelo']} | Fabricante: {m['fabricante']} | "
                  f"Potência: {m['potencia_cv']} cv | Combustível: {m['combustivel']}")

def atualizar_motor():
    print("\n--- Atualizar Motor ---")
    try:
        id_busca = int(input("Digite o ID do motor que deseja atualizar: "))
    except ValueError:
        print("ID inválido.")
        return

    for m in motores:
        if m["id"] == id_busca:
            print(f"Editando '{m['modelo']}' (pressione Enter para manter o valor atual):")
            novo_modelo = input(f"Modelo [{m['modelo']}]: ").strip()
            if novo_modelo: m["modelo"] = novo_modelo

            novo_fab = input(f"Fabricante [{m['fabricante']}]: ").strip()
            if novo_fab: m["fabricante"] = novo_fab

            nova_pot = input(f"Potência em cv [{m['potencia_cv']}]: ").strip()
            if nova_pot:
                try: m["potencia_cv"] = float(nova_pot)
                except ValueError: print("Valor inválido, mantendo anterior.")

            nova_cil = input(f"Cilindrada em cc [{m['cilindrada_cc']}]: ").strip()
            if nova_cil:
                try: m["cilindrada_cc"] = int(nova_cil)
                except ValueError: print("Valor inválido, mantendo anterior.")

            novo_comb = input(f"Combustível [{m['combustivel']}]: ").strip()
            if novo_comb: m["combustivel"] = novo_comb

            print("Motor atualizado com sucesso!")
            return
    print("Motor não encontrado.")

def remover_motor():
    print("\n--- Remover Motor ---")
    try:
        id_busca = int(input("Digite o ID do motor que deseja remover: "))
    except ValueError:
        print("ID inválido.")
        return

    for i, m in enumerate(motores):
        if m["id"] == id_busca:
            removido = motores.pop(i)
            print(f"Motor '{removido['modelo']}' (ID {removido['id']}) removido com sucesso.")
            return
    print("Motor não encontrado.")

def menu():
    while True:
        print("\n===============================")
        print("   SISTEMA DE MOTORES (TESTE)  ")
        print("===============================")
        print("1. Cadastrar motor\n2. Listar todos os motores\n3. Buscar motor\n4. Atualizar motor\n5. Remover motor\n0. Sair")
        opcao = input("Escolha uma opção: ").strip()

        if opcao == "1": cadastrar_motor()
        elif opcao == "2": listar_motores()
        elif opcao == "3": buscar_motor()
        elif opcao == "4": atualizar_motor()
        elif opcao == "5": remover_motor()
        elif opcao == "0":
            print("Encerrando o sistema...")
            break
        else:
            print("Opção inválida! Tente novamente.")

if __name__ == "__main__":
    menu()
